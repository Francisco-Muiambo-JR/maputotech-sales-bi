# MaputoTech Comercial — Análise de Vendas e BI

Projecto de portefólio em desenvolvimento, baseado numa empresa comercial **fictícia** com lojas em Maputo e Matola.

## Objectivo
Transformar registos de vendas em indicadores fiáveis para apoiar decisões sobre receitas, rentabilidade, produtos e desempenho das lojas.

## Tecnologias previstas
Python/pandas, PostgreSQL, SQL, Power BI, Git e GitHub.

## Estado do projecto
**Iteração 1 — levantamento de requisitos e documentação inicial concluídos.** O modelo de dados é preliminar e será validado na fase de implementação. Ainda não existem dados processados, scripts de análise ou dashboards concluídos.

## Organização
- `data/raw/`: dados de origem
- `data/processed/`: dados tratados
- `sql/`: scripts SQL
- `python/`: processamento
- `powerbi/`: relatórios
- `tests/`: verificações

As pastas de implementação estão vazias nesta etapa e serão preenchidas incrementalmente.

## Transparência
A MaputoTech Comercial e os futuros dados do projecto são fictícios. Os resultados não representam uma empresa real.
